# 协作看板

四个角色（定义在 `.claude/agents/`）通过这块看板交接工作。规则：
- 每条任务写明 **负责人**（narrative / designer / gameplay / ui）、**要什么**、**完成标准**；做完把它移到"已完成"并写上提交号。
- 跨角色的需求写成"请求"：`[请求] 来源 → 负责人：内容`。不要直接改别人负责的文件。
- 影响玩法的选择写到"待用户决定"，等用户回答后再做。
- 并行时每个会话在自己的 worktree 分支上工作，合并进 main 由用户（或主会话）决定。

## 待用户决定
- [narrative] **站呼号**：杂波里重复的那串呼号（也是莫尔斯码波形的来源）。建议用虚构呼号，例如 `XR7`（短、好读、莫尔斯码节奏明显）。你也可以给一个自己喜欢的。
- [narrative] **实验发射年份**：建议 1957 年（距 1979 年二十多年，契合"几十年前"）。
- [narrative] **线路图形式**（影响玩法）：A 固定线路、每步 1–3 个节点可选（story.md §4.3 的格式，推荐，易于控制节奏）；B 每局随机生成的分叉地图（类似杀戮尖塔）；C 保持纯线性，只在战斗之间插固定节点。
- [narrative] **时间是否是资源**（影响玩法）：默认挂钟只做表现；也可以让节点消耗时间、天亮前必须走到终点。
- [narrative] **前任值班员**：是否保留这个只通过留言出现的人物（U0、E2）。默认保留，不露面、不写名字。
- [narrative] **结局**：击败源头后是否做"回应 / 静默"双结局（story.md §3.4 U6）。
