# WAVES 美术风格与 UI 规范

> 适用于所有界面与美术资源。新增或修改 UI 前先对照本文件；与本文件冲突的现有实现视为"待迁移"。
> 背景故事见 `docs/design.md` 第 0 节。

## 1. 核心概念：一张工作台

**整个屏幕就是第七中继站值夜班操作员的工作台。**
玩家看到的每一个元素都必须是工作台上的一个**实物**（仪器、仪表、按键、卡片、纸张），信息只能"印"在实物上或"显示"在屏幕里，**不允许漂浮在背景上的文字和数字**。

这条原则同时解决三个问题：
- **风格统一**：所有元素来自同一个世界、同一套材质。
- **信息有家**：每个数值只有一个固定的实物来承载，不重复、不散落。
- **视线有路径**：仪器的摆放顺序就是阅读顺序。

## 2. 四条视觉支柱

1. **物件化**：信息 = 实物。HP 是一块表，能量是一排指示灯，牌堆是读卡器。
2. **暖光冷屏**：桌面、塑料、纸张在暖色台灯下，低饱和；**只有屏幕和指示灯会发光、会饱和**。所以发光的地方就是要看的地方。
3. **信号优先**：波形信息对比度最高，其次是关键数字，最后才是装饰。
4. **安静的手感**：动效模仿真实物件（按键下沉、指针回弹、卡片滑动、磷光余辉），参考《小丑牌》的顺滑；**禁止随机故障、花屏、闪烁**。

## 3. 色彩规范

### 3.1 材质色（不发光，低饱和）
| 名称 | 用途 | 参考值 |
|---|---|---|
| 桌面 | 背景：深色亚麻油地毡 / 旧木桌 | `#1b1714` → 灯下 `#2e2720` |
| 米白塑料 | 所有仪器外壳 | `#e4dccb`，暗部 `#c9c0ab` |
| 黑电木 | 旋钮、铭牌、屏幕护罩、按键底座 | `#1d1d1c` |
| 丝印 | 印在外壳上的文字 | 深棕 `#4a4436` |
| 牛皮纸 / 卡片 | 打孔卡、值班日志 | `#e8dcc0`，墨色 `#3a3328` |
| 金属 | 螺丝、拨杆、刻度环 | `#b9b6ad` |

### 3.2 信号色（只出现在屏幕、指示灯、读数里）
**每种颜色对应一台仪器的磷光**，颜色本身就说明了"这是谁的信号"：

| 颜色 | 含义 | 出现在 |
|---|---|---|
| **琥珀** `#ffb02e` | 杂波（敌人） | 接收机屏幕（琥珀色单色显示器） |
| **品红** `#ff5ce1` | 第二路杂波（干涉双子） | 接收机屏幕 |
| **青白** `#4fd8ff` | 你的发射波 | 发射机屏幕 |
| **P31 绿** `#8dffb4` | 叠加后的结果 | 主示波器屏幕 |

### 3.3 结果语义色（全游戏统一，不得挪作他用）
| 颜色 | 含义 |
|---|---|
| **蓝** `#4f8cff` | 你对敌人造成的伤害 |
| **红** `#ff4d4d` | 你将受到的伤害 |
| **灰** `#9fb8ad`（配斜纹） | 被抵消（格挡） |
| **灯泡黄** `#ffd23f` | 能量 / 发射功率 |

色弱友好：红和蓝之外**必须同时有形状区别**（↑↓ 箭头、灰色的斜纹、数字位置上下分行）。

## 4. 布局与视线引导

### 4.1 工作台布局（1920×1080 基准）

**斜视角桌面**：桌面占满画面的上、左、右三边，木纹带透视向远处汇聚；画面下方能看到桌子前沿，桌沿以外露出一截地板。仪器是摆在桌面上的**独立物件**（各自带落在桌面上的投影），玩家手里的打孔卡在桌沿以外。

```
┌──────────────────────────── 桌面（远处） ────────────────────────────┐
│  ┌──────── 示波器主机（竖立，上宽下窄）──────────────────────────┐  │
│  │ 观察窗/杂波信息 │ 接收屏（琥珀）                               │  │
│  │ 预计 ↑敌 ↓我    │ 主示波器（叠加、强度柱、读数）               │  │
│ [完整度表]──────────────────────────────────────────────────────┘  │
│ （立式，略逆时针转，  [ 发射机（抬起朝向操作员）]     [值班便签]     │
│   挡住主机左下角）                                                    │
│   （立式）  功率灯泡(竖排) · 我方屏（青白） · 发射键                  │
╞═══════════════════════════ 桌子前沿 ═════════════════════════════════╡
│ 抽牌堆          ╲打孔卡扇形╱  ← 玩家手持，缩小叠压            弃牌堆 │
└──────────────────────────────────────────────────────────────────────┘
  点击手牌：整手牌升起、放大、展开到桌面上；按住拖动：直接放到发射机
```

### 4.1.1 尺寸与对齐规范
| 项目 | 值 | 说明 |
|---|---|---|
| 外壳圆角 | 16 | 所有仪器外壳 |
| 窗口 / 按键圆角 | 8 | 显示窗、读数窗、普通按键、弹出面板 |
| 铭牌圆角 | 6 | 黑色铭牌、小标签 |
| 物件间距 | 24 | 仪器之间水平、垂直一致；画面四周留出 40–56 的桌面，让桌子露出来 |
| 窗口内缩 | 18 | 显示窗距外壳边缘 |
| 标题基线 | 外壳顶部向下 36 | 带标题的仪器统一 |
| 透视 | 仪器是桌上的独立设备（`DeskDevice`）：竖立设备上宽下窄，平放设备远窄近宽（透视保持温和）；设备面板先平面布局，再经单应变换显示，输入与特效坐标同样换算 | |
| 遮挡 | 近处设备可以压在远处设备前面（增强真实感），但不得遮挡关键读数（伤害读数条、计数器、屏幕网格） | |
| 对齐 | 同一设备内的屏幕共用格子列（接收屏与主示波器）；发射机屏有自己的格子列 | |

### 4.2 视觉层级（从高到低）
1. **主示波器**：唯一最大、最亮的元素，所有目光的落点。
2. **手牌**：玩家的行动入口。
3. **计数器与发射键**：决策结果与确认动作。
4. **状态**（完整度、功率、敌人名称）。
5. **装饰**（螺丝、丝印、桌面）。

### 4.3 布局规则
- **按问题分区**：上 = 我在面对什么，中 = 会发生什么，下 = 我能做什么。回答同一个问题的信息必须在同一个实物或同一区域里。
- **一值一处**：每个数值只显示一次（例如敌人 HP 只在接收机上，不再在别处重复）。
- **对齐**：三块波形屏共用同一套格子列，上下对齐。
- **留白**：仪器之间留出桌面空隙，不贴边、不堆叠。
- **聚光**：任一时刻最多一个引导高亮；台灯光圈中心落在主示波器上。

## 5. 组件规范

| 组件 | 实物 | 规范 |
|---|---|---|
| 主示波器 | 米白台式示波器 | 黑色护罩 + 圆角显像管；屏内 P31 绿、刻度网格、扫描线、玻璃反光；边缘畸变保留，但必须配合凸面玻璃的光照（护罩边缘阴影、畸变边缘细亮线、随鼓起弯曲的高光），让它读作玻璃鼓起而不是平面特效；合成波为平滑磷光迹线（宽泛光 + 亮芯）；输入波淡显；强度柱按 3.3 语义色 |
| 接收机 | 米白机箱 + 琥珀单色屏 + 圆形观察窗 | 敌人波用折线；敌人形象只出现在**圆形观察窗**里（杂波只能通过屏幕看见）；名称印在铭牌上（意图由波形本身表达，不写字）；敌人 HP 用"杂波强度"条形表 |
| 发射机 | 侧视 L 形米白机箱：竖直面板 + 平放的底座 | 竖直面板正对玩家，只显示你的组合波（折线）+ 虚线"完美抵消"参考；底座上每格一个插槽（放牌目标区域） |
| 计数器 | 辉光管 / 机械翻牌计数器 | 预计对敌（蓝 ↑）、预计受到（红 ↓）；数字最大一级字号；不加文字标题。逐格伤害数字显示在主示波器显像管底部一行 |
| 线路完整度 | 指针式表头 + 数字窗 | 指针显示比例，数字窗显示当前值；受伤预览时指针红色虚影 |
| 发射功率 | 发射机左侧竖排灯泡 | 每回合开始全灭；放入卡牌按费用自下而上点亮；全亮 = 功率已满，发射机持续颤抖并迸出过载火花；再加卡会额外抖动拒绝；不显示数字 |
| 菜单 | 无按钮 | Esc 打开暂停面板（继续 / 返回菜单） |
| 发射键 | 金属底板上的红色蘑菇按键 | 方形拉丝金属底板 + 螺丝 + 镀铬圈；俯视可见帽侧面；可用时就绪灯亮；按下帽沉入再弹回；Enter 同效 |
| 卡牌 | **打孔卡** | 牛皮纸色卡片、切角；上部大号波形图（最大元素）、名称、功率灯（费用）；波形下逐点印数值；底部孔位图案对应波形（装饰）；关键词用小图标。手牌在桌沿以外握成扇形、缩小叠压；点击任意手牌时整手牌升起、放大并展开在桌面上，再点或点别处收回；按住拖动直接放牌 |
| 发射机插槽 | 发射机底座上一排插槽，每格一个，与屏幕同列 | 卡插在第 t 个槽，波从第 t 格向右延伸；插入后变成槽口宽的小标签竖立在槽里（迷你波形 + 逐点数值，波谷红褐色不带负号）；悬停显示放大的完整卡面；拔出即撤回；右键翻转 |
| 抽牌堆 | 读卡器进卡斗（左下） | 卡片叠 + 机械计数器显示数量 |
| 弃牌堆 | 读卡器出卡槽（右下） | 同上 |
| 引导 / 事件 | 值班日志便签（与回合便签同一种纸：横线、红色页边线、胶带） | 贴在相关仪器旁：示波器主机右侧旋钮条（回合便签上方）或桌沿前方手牌两侧；用浅色蜡笔箭头（深色描边，米白机壳和深色桌面上都看得清）指向实物，指向左列的箭头沿机壳顶边走；便签与箭头都不遮挡读数、计数器、发射键和插槽；需要确认的提示在最后一行末尾放一个勾选框（打勾 = 知道了），由操作完成的提示不放；便签落下有轻微回弹，箭头随后画出，勾选后便签滑落淡出；不再有闪烁高亮框 |
| 菜单 | 无常驻按钮 | Esc 打开暂停面板 |
| 胜负 | 日志新的一页 | "第 N 段线路已清除" / "信号丢失" |

**禁止**：通用深色矩形面板、悬浮在桌面上的说明文字、与 3.3 冲突的配色、同一信息的多处重复显示。

## 6. 字体与排版

| 字族 | 用途 | 候选（均需开源可商用，打包进 `assets/fonts/`） |
|---|---|---|
| 丝印体 | 外壳上的标签、铭牌、按键文字 | 思源黑体 / Noto Sans SC（中），配大写无衬线（英） |
| 屏幕体 | 屏幕里的读数、刻度 | 等宽字体，如 JetBrains Mono / Share Tech Mono |
| 手写体 | 值班日志、便签 | 霞鹜文楷（LXGW WenKai） |

**字号层级**（1080p 设计值，实际经 `Assets.fs()` 放大）：
| 层级 | 设计字号 | 用于 |
|---|---|---|
| L1 | 48+ | 预计伤害、完整度数值 |
| L2 | 28–32 | 卡牌名称、敌人名称、计数器 |
| L3 | 20–24 | 标签、意图、日志正文 |
| 最小 | 18 | 任何玩家需要读的文字都不得低于此值 |

- 文字与底色对比度 ≥ 4.5:1。
- 每个界面最多同时使用两个字族；字重只用常规与粗体。

## 7. 动效规范

- **物理感**：卡片有惯性地滑动；按键下沉 0.08s 再回弹；指针摆动带轻微过冲；机械计数器数字滚动。
- **磷光**：屏幕里的迹线有短暂余辉（新旧迹线交叠淡出）。
- **时长**：微反馈 0.1–0.2s；状态变化 0.3–0.5s；整个结算演出 ≤ 1.8s，点击可快进。
- **结算顺序**（与布局一致，视线自上而下再回到中心）：接收机波下落 → 发射机波上升 → 主示波器碰撞（抵消光环、涟漪） → 强度柱 / 读数弹出 → 弹道飞向观察窗或完整度表 → 指针与计数器变化。
- **禁止**：随机撕裂、色块花屏、闪烁、持续抖动、与操作无关的循环动画抢夺注意力。

## 8. 光照与氛围

- 光源：左上方暖色台灯，光圈中心在主示波器；画面边缘自然变暗。
- 屏幕自发光会在周围米白外壳上投下一圈淡淡的同色光。
- 背景就是桌面（深色、带细微纹理），可点缀咖啡杯、铅笔等静物，但不得进入仪器区域。
- 全屏后处理只保留：柔和泛光、轻微颗粒、暗角、碰撞涟漪。

## 10. 资源规范（正式美术）

- 基准分辨率 1920×1080，位图资源按 2× 制作（3840×2160 基准），PNG 带透明通道。
- 命名：`类别_名称_状态.png`，例如 `card_punch_base.png`、`key_fire_pressed.png`。
- 所有路径只登记在 `src/autoload/assets.gd`；缺失时回退到代码绘制的占位。
- **场景按物件拆分**，每个物件一张独立贴图，放在总的桌面背景上：

| 资源 id | 物件 |
|---|---|
| `desk_background` | 斜视角桌面 + 桌子前沿 + 地板（整张背景） |
| `item_receiver` | 接收机外壳（屏幕与观察窗区域留空，由程序绘制内容） |
| `item_main_scope` | 主示波器外壳 |
| `item_transmitter` | 发射机外壳 |
| `item_counter` | 预计计数箱 |
| `item_integrity` | 线路完整度箱 |
| `item_hopper` / `item_tray` | 读卡器进卡斗 / 出卡槽 |
| `card_punch` | 打孔卡底图 |
- 颜色以本文件第 3 节为准，交付时附色板对照。

## 11. 迁移计划（从当前实现到本规范）

| 阶段 | 内容 |
|---|---|
| P1 布局与材质 ✅ | 桌面背景；所有面板改为米白仪器外壳；按 4.1 重排；移除深绿通用面板 |
| P2 仪器化 ✅ | 接收机（琥珀屏 + 圆形观察窗）、发射机（青白屏）、计数器、完整度表头、功率灯、发射键 |
| P1.5 桌面与物件化 ✅ | 斜视角桌面背景（桌沿 + 地板）；仪器拆为独立物件并预留贴图；统一圆角/间距/对齐；手牌握成扇形在桌沿以外，点击整手展开 |
| P3 打孔卡 ✅ | 卡牌改为打孔卡样式；读卡器进卡斗 / 出卡槽与动画；**发射机逐格插槽**（插入后竖立在槽里只露出上半部，波从该槽向右）；视角改平，仅以贴合圆角的顶面/前沿厚度、投影、遮挡保留立体感；移除说明性文字标注（意图、预计、线路完整度、敌/我） |
| P4 值班日志 ✅ | 引导提示改为值班日志便签（`HintSlip` + `DeskNote`）：贴在相关仪器旁、蜡笔箭头指向实物、勾选框代替按钮（事件提示等 narrative 的事件系统落地后沿用同一便签） |
| P5 字体与术语 | 打包三套开源字体；界面文字按第 9 节替换 |
