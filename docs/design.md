# WAVES 游戏设计文档

> 状态：第一里程碑（单场战斗原型）。数值均为原型默认值，存放在 `data/config/rules.json` 与 `data/` 下的 JSON 中。
> 规则改动时同步更新本文档与 `CLAUDE.md`。

## 0. 背景故事（已确认）：第七中继站

**一句话**：1979 年，深山里一座即将关闭的无线电中继站。值夜班的你发现，噪声里有东西在说话——而且它们在靠近。

- **世界**：架空的 1970 年代末，世界靠一张由中继站接力的无线电网络维系。某夜起，大气底噪中出现有规律的波形：一种以波形存在的生物，被称为"**杂波**"。它们顺着线路蔓延，所经之处电器失灵、录音被改写，听到它们的人会慢慢"失真"。唯一的抵抗手段是**相消干涉**：发出与之反相的波把它抹掉。
- **你**：中继站最后一位值夜班的**信号操作员**。工作台上有：米白色示波器（看清杂波）、发射机（发出你的波）、打孔卡读卡器和一叠前辈留下的**波形打孔卡**。
- **机制映射**：卡牌 = 波形打孔卡；牌组 = 卡片匣；抽牌堆/弃牌堆 = 读卡器进卡斗/出卡槽；能量 = 每次扫描的发射功率；敌人意图 = 杂波逼近时在屏幕上显出的形状；结算 = 发射；抵消 = 相消；过量反相 = 你的波穿过杂波击中本体；自我抵消 = 功率浪费；HP = 线路完整度；一局 = 一个夜班，沿线路逐站清理；遗物 = 装上工作台的旧零件（真空管、电容、滤波器）。
- **敌人**：嗡鸣体（市电嗡声活了过来）、尖啸者（麦克风啸叫凝成）、潮汐巨像（电离层长波，先蓄潮再涨满线路）、干涉双子（两路频率相近、互相拍频的载波）、源头（未来 Boss）。
- **伏笔**：杂波的波形里偶尔出现中继站自己的呼号——几十年前这里向深空发射过一次实验信号，回来的是它的回声，已在噪声里长出了自己的意志。作为局外主线，通过值班日志逐步揭开。
- **基调**：孤独、温暖、安静的诡异。深夜、台灯、米白色仪器、咖啡杯，屏幕里却是不该存在的东西。参考：《小丑牌》的手感，《Signalis》《Iron Lung》的值守感，不走恐怖路线。
- **美术与 UI**：整个界面就是操作员的工作台，规范见 `docs/art_direction.md`。

## 1. 概述

- **类型**：单人卡牌构筑 Roguelike（参考《杀戮尖塔》的局内结构：地图 → 战斗 → 奖励 → ……→ Boss）。
- **一句话卖点**：你出的每张牌都是一段波形，和敌人的波在同一条时间轴上**叠加**。把波谷压在敌人的波峰上就是格挡，把波打进敌人波的空隙就是攻击——但你自己的波也会互相抵消。
- **核心乐趣**：每回合是一道"小型信号拼图"：在有限能量、有限手牌下，同时解决"防住多少"和"打出多少"，并且时刻警惕自我干涉。

## 2. 核心规则

### 2.1 波轨与波形
- 波轨是长度为 `track_length`（默认 16）的离散时间轴，每格是一个整数振幅：正 = 波峰，负 = 波谷，0 = 空。
- 波形是整数数组。卡牌放置在起始格 `offset` 时，`P[offset + i] += wave[i]`。
- 越界部分截断（`offtrack_mode`，默认 `truncate`；可选 `forbid` / `wrap`）。

### 2.2 回合流程
1. **回合开始**：能量回满到 `energy_per_turn`（3），抽牌到 `hand_size`（5）张。敌人**随机**决定本回合攻击（见 2.4），并公布意图 E[t]，直接画在波轨上——信息公开，但每回合的攻击无法背板。
2. **布阵阶段**：玩家花能量打出手牌，拖动选择位置。每次拖动都实时预览：叠加后的净波 N[t]、每格的结算结果、本回合预计"受到伤害 / 造成伤害"总数。
   - 结算前已放置的牌可以继续拖动，或拖回手牌撤回并返还能量（`allow_reposition_before_resolve`）。
3. **结算**：玩家点击"结算"，逐格结算（见 2.3），伤害同时生效。
4. **回合结束**：已打出的牌进入弃牌堆，剩余手牌弃掉（与《杀戮尖塔》一致），敌人推进到下一个意图。
5. **胜负**：敌人 HP ≤ 0 → 胜利；玩家 HP ≤ 0 → 失败。伤害同时生效；**同时归零判玩家负**。

### 2.3 逐格结算
设 N[t] = E[t] + P[t]。**互相抵消后剩下的波，就是攻向某一方的波，伤害 = |N[t]|**：

| 情况 | 结果 |
|---|---|
| E[t] ≠ 0 且 sign(N) == sign(E) | 剩余的是敌人的波 → 玩家受到 \|N[t]\| 伤害（没抵消干净，或被自己同向波放大） |
| E[t] ≠ 0 且 N == 0 | 完美抵消，双方都不受伤 |
| E[t] ≠ 0 且 sign(N) ≠ sign(E) | 过量反相，剩余的是玩家的波 → 对敌人造成 \|N[t]\| × `overflow_ratio`（默认 1）伤害 |
| E[t] = 0 | 对敌人造成 \|N[t]\| 伤害（玩家多张波在此也会互相抵消） |

因此即使敌人波覆盖全轨，玩家依然能通过过量反相进攻。

**示例**（8 格片段）：

```
E : 0  0  3  5  3  0  0  0
P1: 0  0 -2 -6 -2  0  0  0
P2: 0  0  0  0  0  2  4  2     ← 脉冲打在空隙里
N : 0  0  1 -1  1  2  4  2
结果: 受到 1+1 = 2 伤害；造成 1（溢出）+ 2+4+2 = 9 伤害
```

若把 P2 左移一格：N[4] = 3 + 2 = 5（与 E 同号且被放大）→ 自伤 5。这种"差一格就天差地别"的手感就是设计核心。

> **数学性质（平衡时必须记住）**：在敌人波格子上，只要玩家的波与 E 反号，该格"对敌伤害 − 对我伤害" = |P| − |E|，与放得是否刚好抵消无关。也就是说，当 `overflow_ratio = 1` 时，"把反相波压在敌人波上"和"把它打进空隙"对双方 HP 差的影响完全相同，区别只是伤害落在谁身上（1:1 交换自己的 HP 和敌人的 HP）。这个交换本身就是取舍：**玩家 HP 整局共用、战斗后不回满**，保住的血会直接帮你扛之后的战斗，所以防守仍然更值钱。形状匹配额外起作用的地方是：敌人波正负交替时的符号对齐、以及空隙里的自我抵消。`overflow_ratio` 保持 1（Q13）。

### 2.4 敌人意图（随机）
- 每个敌人有一个**招式池**，每个招式 = 若干段波形 + 位置，带权重。
- 每回合按权重随机抽取招式；招式可以声明随机偏移范围、随机翻转正负等变化。
- 可选约束（每个敌人在数据里配置）：同一招式最多连续出现几次、某招式之后必接某招式（用于"蓄力 → 释放"这类节奏）。
- 随机数由局内种子驱动，同一种子可复现（便于测试与 bug 复现）。

### 2.5 多敌人：干涉双子
只有一条波轨。**干涉双子是唯一的多敌人关卡**，其他多敌人关卡暂不做。
- 两只双子各自出招，意图都画在同一条轨上，E = E_前 + E_后，两只的波之间也会叠加/抵消（"干涉"）。UI 用两种颜色分别显示两只的波，再显示合成后的 E；结算只看合成后的 E。
- 玩家造成的伤害（空隙伤害 + 溢出伤害）只打**站在前面**的那只。击杀前面那只时多出的伤害作废，不会打到后面那只。
- 每 `swap_interval` 回合（默认 2）双子在回合结束时交换前后位置，意图旁显示交换倒计时。
- 前面那只死亡后，后面那只立刻上前，战斗变成普通单敌人战斗。
- 两只的攻击模式完全不同，"先杀哪只"是玩家的选择（趁想杀的那只站在前面时集中进攻）：
  - **峰子 Crest**：宽而平的正波，稳定施压。
  - **谷子 Trough**：稀疏但高振幅的负尖峰。
  - 两只正负相反，波重叠时会互相抵消；杀掉其中一只后，另一只的波就不再被抵消，变得更危险。

### 2.6 牌堆
标准构筑结构：抽牌堆、手牌、弃牌堆、消耗堆。抽牌堆空时把弃牌堆洗回。初始牌组约 10 张。

### 2.7 一局的结构（实现说明：节点框架）
一局 = `data/config/run.json` 里按顺序排列的**节点**（`RunState`，`src/core/run_state.gd`）。HP、牌组（`deck_ids`）、遗物（`relic_ids`）在节点之间延续，HP 不自动回满。目前框架只决定"怎么运作"，各节点放什么、放几个由 narrative / designer 决定。

| 节点 `type` | 字段 | 行为 |
|---|---|---|
| `fight` | `encounter` | 用当前牌组 + 遗物开战；胜利进入下一节点，失败本局结束。 |
| `reward` | 可选 `size`、`pool`（卡牌 id 列表） | 生成卡牌奖励：从卡池按 `reward_weight` 加权、不放回抽 `size`（缺省 `rules.reward_offer_size`）张；选一张加入牌组，或跳过（`rules.reward_allow_skip`）。 |
| `rest` | 可选 `effects` | 应用效果后继续；没有 `effects` 就什么也不做（占位）。 |
| `event` | `event`（事件 id） | 占位：事件引擎完成前，UI 以选中的效果列表调用 `complete_event`。 |

- **旧格式兼容**：`{"encounters": [...]}` 仍可读取，等同于只有 fight 节点。仓库里的 run.json 已迁移为 `nodes` 格式（内容不变：仍是 4 场战斗）。
- **局内效果**（`RunEffects`）：`hp`（± 回血/扣血，降到 0 本局失败）、`max_hp`、`add_card`、`remove_card`、`add_relic`。休息与事件共用；新增类型需改代码 + 测试。
- **卡池**：卡牌 JSON 可选字段 `reward_weight`（缺省 1；0 = 不进默认卡池）。节点 `pool` 显式指定时只从中抽。
- **可复现**：战斗种子仍为 `局种子 + 已胜场数 × 7919`（与之前一致）；其他节点的随机数由局种子与节点序号派生。奖励是纯函数，同一节点重复生成结果相同，所以无需存档。
- **数值缺省**（暂定，由 designer 调）：`reward_offer_size` = 3，`reward_allow_skip` = true。
- **遗物钩子**（`Relic` 基类 + `RelicRegistry`，暂无正式遗物）：`on_combat_start` → 每回合 `on_turn_start`（抽牌、敌人出招之后）→ `modify_result`（在 `Combat.preview()` 内调用，预览与结算永远一致；改完逐格伤害调 `result.recount()`）→ `after_resolve`（本回合伤害生效后、判定胜负前）。

## 4. 机制延伸建议（之后的里程碑）

### 4.1 卡牌效果分类（数据中的 `effects` 字段）
- **反相 Invert**：放置时可翻转正负（关键词）；或"将一段已放置的波反相"。
- **拉伸 Stretch ×k**：线性插值，端点保持不变，长度 n → (n−1)·k + 1，四舍五入（0.5 远离 0）。`[2,4]` ×2 → `[2,3,4]`；`[2,4,2]` ×2 → `[2,3,4,3,2]`。单格波（如 `[7]`）拉伸后不变。
- **压缩 Compress**：反之，取样合并，波更窄更集中。
- **平移 Shift**：把一张已放置的牌或**敌人的波**左右移动 n 格 —— 移动敌人波非常有趣，可以把敌人的波峰挪到你的波谷上。
- **放大 Amplify ×k / 衰减 Dampen**：缩放某段波的振幅（可作用于敌人波）。
- **回声 Echo +d**：在 d 格之后放一份副本（可带衰减）。
- **驻波 Standing**：这张波留在波轨上持续 N 回合（跨回合布阵）。
- **整流 Rectify**：把某段波的负值变成正值（|x|）。
- **相位锁 Phase Lock**：本回合若某格 N 恰好为 0（完美抵消），获得能量/抽牌。
- **共振溢出 Overdrive**：本回合过量反相的溢出伤害 ×2。

### 4.2 敌人类型
- **追相者**：意图会朝你上回合放置最多的位置偏移。
- **镜像者**：本回合意图 = 你上回合净波的反相 —— 你打得越猛，它回得越狠。
- **噪声体**：部分格子意图隐藏（显示为"?"），结算时才揭晓。
- **宽带者**：全轨低振幅 —— 强迫你放弃进攻或接受小伤。
- **脉冲星（Boss）**：数回合蓄力后一个超高单格尖峰，必须精确堆叠多张反相牌。
- **相移 Boss**：每回合结算前把整条波轨上**你的**波平移 1 格（预览中可见）。

### 4.3 遗物
- **示波器**：可以看到下回合的意图。
- **阻尼器**：敌人每格振幅绝对值 -1（最小 0）。
- **谐振腔**：每回合第一张牌振幅 +1。
- **全波整流器**：空隙格里的负振幅造成双倍伤害。
- **接地线**：每回合第一次自伤减为 0。
- **频谱仪**：波轨 +2 格。
- **陷波滤波器**：完美抵消的格子每格回 1 HP。
- 非位置性防御（类似"格挡"）不进入基础规则，只通过遗物提供（Q8）。

### 4.4 流派
1. **完美相消流**：追求 N = 0，靠"相位锁/陷波"拿资源与回血。
2. **共振放大流**：在空隙格叠加同向波，配合放大、谐振腔。
3. **过载溢出流**：大振幅反相波砸在敌人波上，同时防守和进攻，配合溢出加成。
4. **驻波/回声流**：布置跨回合持续的波，越打越满。
5. **调制操控流**：平移/反相/拉伸**敌人**的波，让敌人的波去"撞"自己的空隙。

## 5. 表现与交互（原型）

**美术方向**：老式台式示波器与电子仪器，整体气质参考《小丑牌》——效果是风格与手感，不是视觉干扰。

**战斗布局**
```
┌ 敌人形象/HP/意图 │ [敌方信号面板：平板边框 · 折线]                         ┐
│ ↑ 预计对敌（大数字）│ [中间台式示波器：铭牌 · 显像管（墨绿流动底纹、边缘畸变）   │
│ ↓ 预计受到        │   敌人波 + 你的组合波 + 合成结果（平滑曲线）         │
│ 结算按钮          │   强度柱：灰=被抵消 红=打你 蓝=打敌人 · 粒子 · 读数]      │
│ 玩家形象/能量◆/HP │ [我方信号面板：平板边框 · 折线组合波 · 虚线完美抵消]            │
└ 抽牌堆▤        手牌（轻微摇摆，悬停放大）                    弃牌堆▤  ┘
```
- 少文字、多图标：牌堆用卡牌堆图标 + 大号数量，能量只用菱形图标，HP 用大号数字；操作说明由新手引导给出。
- 三块波形面板共享同一套格子列，鼠标所在列会同时高亮；双子在左栏上下排列，前排在上，交换时滑动换位。
- 我方面板的虚线 = 敌人波的反相，即"刚好完美抵消"所需的波形。
- **让"抵消"看得见**：中间示波器每格的强度柱以敌人原本的攻击为基准——被你抵消的部分变灰，剩下打你的部分是红色，你打到敌人的部分（打进空隙或反相过量）是蓝色；蓝色粒子从你的攻击处飘向敌人，红色粒子落向你，抵消处有灰色闪光。core 层结算直接给出每格 `blocked`（格挡量），UI 不自行计算。
- 抽牌/弃牌动画：抽到的牌从左下抽牌堆飞入手牌，回合结束手牌与打出的牌飞入右下弃牌堆，洗牌时牌背从弃牌堆飞回抽牌堆。

**结算动画**
1. 上下两块面板里的波分别射出，进入中间示波器（敌人波从上方落入、你的波从下方升起）。
2. 碰撞：被抵消的格子出现柔和光环，整屏一圈平滑冲击波涟漪；强度柱、合成曲线和读数从左到右回弹弹出。
3. 剩余伤害化为弹道：绿色飞向前排敌人，红色飞向玩家。
4. 命中：形象闪白、阻尼摆动、挤压，伤害数字弹出；你受伤时再一圈轻涟漪。

**参考图**：合成波参考 Tektronix 465B 的明亮绿色磷光迹线；示波器屏幕底参考 Leader LBO-310A 的深绿玻璃与浅绿刻度。

**画面处理**：中间示波器的显像管有深绿磷光玻璃底、边缘畸变、扫描线和辉光；全屏只有柔和泛光、轻微色差、颗粒、暗角；游戏背景是暗色实验台面（暖调深灰、台灯光晕、细微纹理与漂浮灰尘，不用网格和绿色）。没有随机撕裂、花屏、闪烁。F2 关闭全屏后处理。

**交互**
- 拖动手牌到波形区域（上下面板和中间示波器都可以），波形吸附到格子，鼠标抓住波形中点，所有预览实时刷新。
- 拖动时右键或 R：反相（仅"可反相"的牌）；已放置的可反相波上右键也可翻转。
- 抓起已放置的波可以移动；拖出示波器即撤回并返还能量。
- 非波形牌（调谐）：拖到手牌区以上任意位置松开即打出。
- Enter / 空格 / "结算"按钮：结算。
- 预览与结算调用 core 层同一个函数，UI 不自行计算。

**一局流程（原型）**：主菜单"开始新的一局" → 信号链（4 个节点：嗡鸣体 → 尖啸者 → 潮汐巨像 → 干涉双子）→ 依次战斗，HP 延续 → 通关或失败。主菜单另保留"单场测试"。

**新手引导**：第一局第一战分步引导（敌方示波器 → 我方示波器 → 拖一张牌 → 碰撞预演 → 撤回 → 结算 → HP 延续）；新机制首次出现时提示（过量反相、调谐、双极、回声、尖啸者、潮汐蓄力、干涉双子）。每条只出现一次，可在主菜单重置。

## 6. 设计决定记录

| # | 问题 | 决定 |
|---|---|---|
| Q1 | 越界 | 截断超出部分（`offtrack_mode = truncate`，未提异议，沿用默认） |
| Q2 | 结算前能否调整 | 可以拖动/撤回并返还能量（未提异议，沿用默认） |
| Q3 | 拉伸定义 | 线性插值（见 4.1） |
| Q4 | 多敌人 | 取消多波轨，只有一条波轨；唯一的多敌人关卡是干涉双子（见 2.5） |
| Q5 | 正负对称 | 需要匹配形状（逐格计算）；基础牌组正负平衡兜底 |
| Q6 | 完全公开 | 意图公开，但每回合攻击随机抽取（见 2.4） |
| Q7 | 伤害规模 | 注意数值，前期低 |
| Q8 | 非位置性防御 | 基础规则不加，只靠遗物 |
| Q9 | 敌人全轨覆盖 | 允许，用于高级敌人；玩家可以靠过量反相反击 |
| Q10 | 溢出 | 抵消后剩下的波攻向对应一方，伤害 = 剩余振幅的绝对值（见 2.3）；`overflow_ratio` 可调 |
| Q11 | 自伤提示 | 不做额外强调，靠前期低数值让玩家自己学会（预览照常显示每格结果） |
| Q12 | 同时死亡 | 判玩家负 |
| Q13 | 溢出比例 | 保持 1：1:1 换血仍是取舍，因为玩家 HP 整局共用、不回满 |
