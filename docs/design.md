# WAVES 游戏设计文档

> 状态：第一里程碑（单场战斗原型）。数值均为原型默认值，存放在 `data/config/rules.json` 与 `data/` 下的 JSON 中。
> 规则改动时同步更新本文档与 `CLAUDE.md`。

## 1. 概述

- **类型**：单人卡牌构筑 Roguelike（参考《杀戮尖塔》的局内结构：地图 → 战斗 → 奖励 → ……→ Boss）。
- **一句话卖点**：你出的每张牌都是一段波形，和敌人的波在同一条时间轴上**叠加**。把波谷压在敌人的波峰上就是格挡，把波打进敌人波的空隙就是攻击——但你自己的波也会互相抵消。
- **核心乐趣**：每回合是一道"小型信号拼图"：在有限能量、有限手牌下，同时解决"防住多少"和"打出多少"，并且时刻警惕自我干涉。

## 2. 核心规则

### 2.1 波轨与波形
- 波轨是长度为 `track_length`（默认 16）的离散时间轴，每格是一个整数振幅：正 = 波峰，负 = 波谷，0 = 空。
- 波形是整数数组。卡牌放置在起始格 `offset` 时，`P[offset + i] += wave[i]`。
- 越界部分截断（默认，待确认，见 Q1）。

### 2.2 回合流程
1. **回合开始**：能量回满到 `energy_per_turn`（3），抽牌到 `hand_size`（5）张。敌人公布本回合意图 E[t]，直接画在波轨上。
2. **布阵阶段**：玩家花能量打出手牌，拖动选择位置。每次拖动都实时预览：叠加后的净波 N[t]、每格的结算结果、本回合预计"受到伤害 / 造成伤害"总数。
   - 原型默认：结算前已放置的牌可以继续拖动，或拖回手牌撤回并返还能量（Q2）。
3. **结算**：玩家点击"结算"，逐格结算（见 2.3），伤害同时生效。
4. **回合结束**：已打出的牌进入弃牌堆，剩余手牌弃掉（与《杀戮尖塔》一致），敌人推进到下一个意图。
5. **胜负**：敌人 HP ≤ 0 → 胜利；玩家 HP ≤ 0 → 失败。同一次结算双方同时归零时，判定玩家胜利（待确认，Q12）。

### 2.3 逐格结算
设 N[t] = E[t] + P[t]：

| 情况 | 结果 |
|---|---|
| E[t] ≠ 0 且 sign(N) == sign(E) | 玩家受到 \|N[t]\| 伤害（没抵消干净，或被自己同向波放大） |
| E[t] ≠ 0 且 N = 0 或 sign(N) ≠ sign(E) | 完全防住；反向溢出 \|N[t]\|（若反号）默认浪费，记录为 `overflow` 供"反射"类效果使用 |
| E[t] = 0 | 对敌人造成 \|N[t]\| 伤害（玩家多张波在此也会互相抵消） |

**示例**（8 格片段）：

```
E : 0  0  3  5  3  0  0  0
P1: 0  0 -2 -4 -2  0  0  0     ← 谷脉冲放在敌人波峰上
P2: 0  0  0  0  0  2  4  2     ← 脉冲打在空隙里
N : 0  0  1  1  1  2  4  2
结果: 受到 1+1+1 = 3 伤害；造成 2+4+2 = 8 伤害
```

若把 P2 左移一格：N[4] = 3 + 2 = 5（与 E 同号且被放大）→ 自伤 5，同时对敌人只打出 4+2 = 6。这种"差一格就天差地别"的手感就是设计核心。

### 2.4 牌堆
标准构筑结构：抽牌堆、手牌、弃牌堆、消耗堆。抽牌堆空时把弃牌堆洗回。初始牌组约 10 张。

## 3. 原型内容（第一里程碑）

### 3.1 卡牌（约 10 张）

| 名称 | 费 | 波形 | 定位 |
|---|---|---|---|
| 脉冲 Pulse | 1 | `[2, 4, 2]` | 基础正波，攻防两用 |
| 谷脉冲 Trough | 1 | `[-2, -4, -2]` | 基础负波 |
| 方波 Square | 1 | `[3, 3, 3, 3]` | 平稳、宽，适合抵消方波型敌人 |
| 反方波 Anti-Square | 1 | `[-3, -3, -3, -3]` | 同上，负向 |
| 锯齿 Saw | 1 | `[1, 2, 3, 4, 5]` | 斜坡，对付渐强型攻击 |
| 全周期 Full Cycle | 1 | `[2, 4, 2, 0, -2, -4, -2]` | 正负各一半，可"一张牌同时防两种波" |
| 尖峰 Spike | 1 | `[7]` | 单格高爆发，要精确放置 |
| 涌浪 Swell | 2 | `[1, 2, 3, 4, 3, 2, 1]` | 长而高，高费大伤害/大防御 |
| 双极 Bipolar ★ | 1 | `[3, 3, 3]`，**可反相** | 放置时可按键/右键翻转正负 |
| 回声 Echo ★ | 1 | `[3, 2, 1]`，**回声 +5** | 在起点后 5 格再放一份副本（副本也可能自我抵消） |
| 调谐 Tune ★ | 0 | 无波形，**抽 2 张** | 非波形功能牌，测试数据驱动的效果系统 |

★ = 有特殊效果。初始牌组：脉冲×2、谷脉冲×2、方波、反方波、全周期、尖峰、双极、调谐（10 张）。其余作为可替换测试卡。

### 3.2 敌人（3 种）

意图以"波形 + 位置"列表定义，按循环顺序出招：

| 敌人 | HP | 节奏 | 意图特点 |
|---|---|---|---|
| 嗡鸣体 Drone | 40 | 稳定，每回合一段 | 宽而低的方波 `[2,2,2,2,2,2]`，位置每回合平移 —— 新手教学型 |
| 尖啸者 Shrieker | 32 | 快、碎 | 2–3 个高振幅单格尖峰，正负交替（如 `[6]`、`[-6]`）—— 考验精确放置，空隙多、攻击窗口大 |
| 潮汐巨像 Tide Colossus | 70 | 慢，两回合一循环 | 回合 A：几乎覆盖全轨的大正弦（防御回合）；回合 B：只有小波（"蓄力"，进攻窗口） |

## 4. 机制延伸建议（之后的里程碑）

### 4.1 卡牌效果分类（数据中的 `effects` 字段）
- **反相 Invert**：放置时可翻转正负（关键词）；或"将一段已放置的波反相"。
- **拉伸 Stretch ×k**：每个采样重复 k 次（`[2,4]` → `[2,2,4,4]`），覆盖更宽、单格振幅不变。
- **压缩 Compress**：反之，取样合并，波更窄更集中。
- **平移 Shift**：把一张已放置的牌或**敌人的波**左右移动 n 格 —— 移动敌人波非常有趣，可以把敌人的波峰挪到你的波谷上。
- **放大 Amplify ×k / 衰减 Dampen**：缩放某段波的振幅（可作用于敌人波）。
- **回声 Echo +d**：在 d 格之后放一份副本（可带衰减）。
- **驻波 Standing**：这张波留在波轨上持续 N 回合（跨回合布阵）。
- **整流 Rectify**：把某段波的负值变成正值（|x|）。
- **相位锁 Phase Lock**：本回合若某格 N 恰好为 0（完美抵消），获得能量/抽牌。
- **反射 Reflect**：本回合防御溢出值转化为对敌伤害。

### 4.2 敌人类型
- **追相者**：意图会朝你上回合放置最多的位置偏移。
- **镜像者**：本回合意图 = 你上回合净波的反相 —— 你打得越猛，它回得越狠。
- **噪声体**：部分格子意图隐藏（显示为"?"），结算时才揭晓。
- **宽带者**：全轨低振幅 —— 强迫你放弃进攻或接受小伤。
- **干涉双子**：两个敌人的波在同一轨道上，彼此之间也会叠加/抵消（击杀一个会改变另一个的有效波形）。
- **脉冲星（Boss）**：数回合蓄力后一个超高单格尖峰，必须精确堆叠多张反相牌。
- **相移 Boss**：每回合结算前把整条波轨上**你的**波平移 1 格（预览中可见）。

### 4.3 遗物
- **示波器**：可以看到下回合的意图。
- **阻尼器**：敌人每格振幅绝对值 -1（最小 0）。
- **谐振腔**：每回合第一张牌振幅 +1。
- **全波整流器**：空隙格里的负振幅造成双倍伤害。
- **接地线**：每回合第一次自伤减为 0。
- **频谱仪**：波轨 +2 格。
- **陷波滤波器**：完美抵消的格子每格回 1 HP。

### 4.4 流派
1. **完美相消流**：追求 N = 0，靠"相位锁/陷波"拿资源与回血。
2. **共振放大流**：在空隙格叠加同向波，配合放大、谐振腔。
3. **反射溢出流**：故意过量反相，把溢出反射给敌人。
4. **驻波/回声流**：布置跨回合持续的波，越打越满。
5. **调制操控流**：平移/反相/拉伸**敌人**的波，让敌人的波去"撞"自己的空隙。

## 5. 表现与交互（原型）
- 波轨：横向 16 格的网格，中线为 0。敌人波（红）、每张玩家波（蓝，半透明、各自一条线）、净波（黄，粗线）分层绘制；同时用柱状条显示每格数值。
- 每格下方标记结算结果：绿色"→敌 X"、红色"←受 X"、灰色"挡"。
- 顶部汇总：本回合预计 造成 / 受到 伤害，敌我 HP 条上同时显示"预计扣血"幽灵段。
- 拖动手牌到波轨上时，卡牌波形跟随鼠标吸附到格子，实时刷新以上全部预览；松手确认放置并扣能量。
- 全部预览由 core 层同一个结算函数计算，UI 不自行计算。

## 6. 待决定问题（需要你拍板）

**会影响原型实现的（我已按默认值先做，你确认或改）**

- **Q1 越界**：卡牌部分超出波轨时，(a) 截断超出部分【默认】；(b) 不允许放置；(c) 环形回绕到另一端。截断让长波在边缘也能用但会"浪费"，回绕更有趣但不直观。
- **Q2 结算前能否调整**：已打出的牌在点击"结算"前，(a) 可以拖动/撤回并返还能量【默认，拼图手感更好】；(b) 一旦放下就固定（更紧张，但误操作挫败感强）。
- **Q3 拉伸的定义**：(a) 采样重复 `[2,4]→[2,2,4,4]`【默认，总量翻倍】；(b) 插值 `[2,4]→[2,3,4]`。（原型不做拉伸卡，影响后续）
- **Q4 单敌人 vs 多敌人**：原型只做单敌人。多敌人时空隙伤害打给谁？建议：共享一条波轨，空隙伤害打给"当前目标"，或按格子归属（每个敌人有自己的"领域"格段）。

**可能不好玩的地方**

- **Q5 正负对称**：空隙格伤害是 |N|，正负波攻击力完全一样，正负只在"防御"和"自我抵消"上有区别。这意味着手里没有对应符号的牌就防不住，可能导致"抽不到反相牌=挨打"的挫败。建议：基础牌组正负平衡，"可反相"关键词常见；或让防御只需"振幅相反"而不需完全匹配形状（目前已是这样，按格计算）。
- **Q6 纯信息完全拼图**：每回合信息完全公开，可能变成"算最优解"的分析瘫痪，也可能让高手觉得每回合都是固定解。缓解手段：手牌随机性、部分隐藏意图的敌人、限制回合内调整次数。需要试玩判断。
- **Q7 伤害规模**：一段 `[2,4,2]` 未防住就是 8 伤害，满轨 16 格的伤害上限可以很高。原型 HP：玩家 60、敌人 32–70。需要试玩校准，也可以考虑"每格伤害上限"或整体缩放系数。
- **Q8 是否需要非位置性防御**（类似"格挡值"）：目前防御 100% 来自抵消。好处是纯粹，坏处是没有"保底"。建议原型先不加，靠遗物/卡牌补充（如"接地线"）。
- **Q9 敌人全轨覆盖**：如果敌人波覆盖全部 16 格，玩家无法进攻。设计约束：普通敌人必须留空隙；全覆盖只作为"防御回合"出现，并在意图上明确提示。
- **Q10 过量反相浪费**：反号溢出直接浪费，会让"多放一点保险"没有代价——这其实是好事（鼓励稳妥），但也让精确放置的奖励只来自"省下的牌"。是否给"完美抵消"额外奖励（相位锁），可以作为流派而不是基础规则。
- **Q11 自伤是否过于惩罚**：同向放大敌人波会让自己受伤，这是规则的直接推论，对新手可能不直观。预览会把这种格子标红高亮。
- **Q12 同时死亡**：同一次结算双方同时归零，判玩家胜【默认】还是负？
